# Publish Feral Node in about 10 minutes

1. Log in to GitHub as `feralnode`.
2. Create a **public** repository named `feralnode.github.io`.
3. Upload `index.html`, `sam-mayahi.vcf`, and `feral-node-qr.png` into the repository's root, and include the `assets` folder containing `feral-node-fox.png`.
4. Go to **Settings → Pages**. Select deployment from branch `main`, folder `/ (root)` if not already selected.
5. Wait for the deployment to finish, then open https://feralnode.github.io/ on your phone.
6. Test each link and tap **Save contact** to confirm the vCard downloads/opens correctly.
7. The QR image and NFC tag should point to https://feralnode.github.io/. Do not distribute them until the page is live.

No paid hosting is required for this static page. GitHub Pages is free for public repositories.
