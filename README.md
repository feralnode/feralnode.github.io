# Feral Node — digital contact card

A small, mobile-friendly static contact page. No subscription or build tools required.

## Files
- `index.html` — the contact card
- `assets/feral-node-fox.png` — the exact black-and-white fox logo selected for the brand
- `sam-mayahi.vcf` — downloadable contact card
- `feral-node-qr.png` — QR code pointing to `https://feralnode.github.io/`
- `DEPLOYMENT.md` — quick GitHub Pages instructions

## Publish for free with GitHub Pages
1. Sign in to GitHub as `feralnode`.
2. Create a **public** repository named exactly `feralnode.github.io`.
3. Upload `index.html`, `sam-mayahi.vcf`, and `feral-node-qr.png` to the repository root, and upload the `assets` folder with its logo file.
4. Open **Settings → Pages** and ensure deployment from the `main` branch and `/ (root)` is selected if needed.
5. Wait for GitHub Pages to publish the site at `https://feralnode.github.io/`.
6. Test the page on your phone and test the Save contact button.
7. Only after the page is live, write `https://feralnode.github.io/` to your NFC tag. The included QR code points to this same URL.

## Before sharing
The QR code and NFC URL assume the GitHub Pages address above. They will not work until you publish the repository. If GitHub Pages chooses a different URL, regenerate the QR code and update the NFC tag to match it.
